TASK:
Create the OSTree rootfs conversion scripts and the Live ISO packaging scripts for Kepler OS.

FILE 1: `ostree-recipe/scripts/prepare-ostree-layout.sh`
1. Use `#!/bin/bash` and `set -euo pipefail`.
2. Accept the staging rootfs path as `$1` (`ROOTFS="$1"`).
3. Convert the Debian filesystem inside `"$ROOTFS"` to the immutable OSTree layout:
   - Move `"$ROOTFS/etc"` to `"$ROOTFS/usr/etc"` (OSTree 3-way merge template directory).
   - Remove `"$ROOTFS/home"`, `"$ROOTFS/opt"`, `"$ROOTFS/srv"`, `"$ROOTFS/mnt"`, and `"$ROOTFS/root"` and recreate them as symlinks:
     * `ln -s var/home "$ROOTFS/home"`
     * `ln -s var/opt "$ROOTFS/opt"`
     * `ln -s var/srv "$ROOTFS/srv"`
     * `ln -s var/roothome "$ROOTFS/root"`
     * `ln -s run/media "$ROOTFS/media"`
   - Ensure `"$ROOTFS/sysroot"` and `"$ROOTFS/ostree"` directories exist.
   - Move the kernel image `/boot/vmlinuz-*` and initramfs `/boot/initrd.img-*` (built with `dracut --add ostree`) into `"$ROOTFS/usr/lib/modules/${KVER}/vmlinuz"` and `"$ROOTFS/usr/lib/modules/${KVER}/initramfs.img"`, then empty `"$ROOTFS/boot"`.

FILE 2: `build-ostree-commit.sh`
1. Use `#!/bin/bash` and `set -euo pipefail`.
2. Define `REPO_DIR="/workspace/profile/config/includes.chroot/ostree-repo"` and `STAGE_DIR="/workspace/rootfs_staging"`.
3. Initialize the OSTree repository if not initialized: `ostree --repo="$REPO_DIR" init --mode=archive-z2`.
4. Build the Debian Testing rootfs in `"$STAGE_DIR"` using `mmdebstrap` (or `debos`) with the package lists in `/workspace/profile/config/package-lists/*.list.chroot` and the `Voyager-PPA` repository.
5. Copy all immutable system files from `/workspace/ostree-recipe/overlays/` into `"$STAGE_DIR/"`.
6. Execute `/workspace/ostree-recipe/scripts/prepare-ostree-layout.sh "$STAGE_DIR"`.
7. Commit `"$STAGE_DIR"` to the OSTree repository:
   `ostree --repo="$REPO_DIR" commit --branch="kepler/testing/x86_64-v3/gnome" --subject="Kepler OS x86-64-v3 Atomic Build $(date -u +%Y%m%d.%H%M)" "$STAGE_DIR"`
8. Run `ostree --repo="$REPO_DIR" summary -u`.

FILE 3: `profile/auto/config`
1. Use `#!/bin/sh` and `set -e`.
2. Run `lb config noauto` with `--mode debian`, `--distribution testing`, `--debian-installer none`, `--architectures amd64`, `--linux-flavours "cachyos-bore-v3"`, `--archive-areas "main contrib non-free non-free-firmware"`, `--bootappend-live "boot=live components quiet splash zswap.enabled=0"`, `--iso-application "Kepler OS Immutable"`, `--iso-publisher "Arda-Tech / Voyager Project"`, `--iso-volume "KEPLER_OSTREE_LIVE"`, `--security false`, `--updates false`, `"${@}"`.

FILE 4: `build-iso.sh`
1. Use `#!/bin/bash` and `set -euo pipefail`.
2. Verify that `/workspace/profile/config/includes.chroot/ostree-repo/config` exists before running `lb build`.
3. Copy `/workspace/profile/` to `/workspace/work/`, run `lb config && lb build`, and move the resulting `.iso` to `/workspace/build_out/kepler-os-immutable-x86_64-v3-$(date +%Y%m%d).iso`.
