# PROMPT ID: 5.4 | TITLE: AUTOMATED ISO BUILD AND GITHUB RELEASES WORKFLOW
# TARGET MODEL: Gemini 3.8 Flash [HIGH] (Raw: HIGH)
# SOURCE MODULE: 05_CI_CD_VOYAGER_PPA_AND_FLATPAK_STE100.md

ROLE: Linux Release Engineer & GitHub Actions Security Architect.
STANDARD: ASD-STE100 (Simplified Technical English). Output only valid YAML code with strict 2-space indentation. Do not include conversational prose.

TASK:
Create a GitHub Actions workflow file at `.github/workflows/release-kepler-iso.yml` to build the Kepler OS Immutable Live ISO, generate cryptographic checksums (`SHA256SUMS`) and detached GPG signatures (`SHA256SUMS.gpg` and `.iso.asc`), and publish them to GitHub Releases.

TECHNICAL REQUIREMENTS:
1. Trigger the workflow on Git tags matching `v*` (for example, `v2026.11.01`), on a monthly schedule (`cron: '0 4 1 * *'`), and via `workflow_dispatch`.
2. Set workflow `permissions`:
   - `contents: write` (required to create GitHub Releases and upload release assets).
   - `packages: write`.
3. Run on `ubuntu-latest` with free disk space cleanup before building.
4. Step 1 (Free Disk Space & Install Dependencies):
   - Remove unnecessary pre-installed runner SDKs (`/usr/local/lib/android`, `/usr/share/dotnet`, `/opt/ghc`) to free at least 45 GB of disk space for the OSTree rootfs and Live ISO build.
   - Install `podman`, `gnupg`, `coreutils`, `zstd`, and `gh` (GitHub CLI).
5. Step 2 (Import GPG Signing Key & Generate MOK Keys):
   - Import `VOYAGER_GPG_PRIVATE_KEY` in batch mode and read `VOYAGER_GPG_KEY_ID`.
   - Run `make builder` and `make mok-keys` to initialize the isolated builder container and UEFI Secure Boot MOK certificates.
6. Step 3 (Build OSTree Commit, Live ISO, and OCI Archive):
   - Run `make ostree-commit` and `make iso` to generate `build_out/kepler-os-immutable-x86_64-v3-*.iso`.
7. Step 4 (Generate SHA256SUMS and Detached GPG Signatures):
   - Change directory to `build_out/`.
   - Generate `SHA256SUMS` for all `.iso` files using `sha256sum kepler-os-immutable-x86_64-v3-*.iso > SHA256SUMS`.
   - Create a detached ASCII-armored GPG signature for the checksum file (`gpg --batch --yes --default-key "${VOYAGER_GPG_KEY_ID}" --armor --detach-sign --output SHA256SUMS.gpg SHA256SUMS`).
   - Create a detached ASCII-armored GPG signature directly for the ISO file (`gpg --batch --yes --default-key "${VOYAGER_GPG_KEY_ID}" --armor --detach-sign --output "${ISO_FILE}.asc" "${ISO_FILE}"`).
   - Verify both signatures using `gpg --verify SHA256SUMS.gpg SHA256SUMS` and `sha256sum -c SHA256SUMS`.
8. Step 5 (Publish to GitHub Releases):
   - Determine the release tag (`${GITHUB_REF_NAME}` or `rolling-$(date -u +%Y%m%d)`).
   - Generate ASD-STE100 release notes summarizing the active `linux-cachyos-bore-v3` kernel version, OSTree commit hash, `x86-64-v3` hardware requirement, GPG verification instructions, and the EU AI Act / NASA & ESA non-affiliation notice.
   - Publish the `.iso`, `.iso.asc`, `SHA256SUMS`, and `SHA256SUMS.gpg` files to GitHub Releases using `gh release create` (or `softprops/action-gh-release@v2`).
